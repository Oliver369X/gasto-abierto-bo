# Requisitos de referencia

Documentación de trazabilidad de requisitos del producto. Los campos deben implementarse contra **descargas oficiales** de Presupuesto Abierto (`https://abierto.economiayfinanzas.gob.bo/descargas`), no contra hojas de cálculo internas.

Ver:

- `docs/sources/presupuesto_abierto.md`
- `python -m scripts.cli gasto fetch-presupuesto --list-only`
- `python -m scripts.cli gasto fetch-presupuesto`
